#+TITLE: idsmall
#+STARTUP: content

=idsmall= allocates short, human-typable identifiers that carry a reversibly
scrambled timestamp. A canonical identifier is seven case-sensitive Bitcoin
Base58 characters: one seed character followed by six characters encoding the
universal time, scrambled by a bijection derived from that seed.

#+BEGIN_SRC lisp
(idsmall:identifier-generate)
;; => "31uWB8L"

(idsmall:identifier-display "31uWB8L")
;; => "3-1uWB8L"

(idsmall:identifier-timestamp "31uWB8L")
;; => 3993000000
#+END_SRC

Identifiers are short enough to read aloud and type. They sort into no
meaningful order. The timestamp is recoverable with this library.

* Format

The alphabet omits =0=, =O=, =I=, and =l=, so no two characters look alike. The
seed character selects an odd multiplier and an offset, both derived from the
seed index by the MurmurHash3 32-bit finalizer over two fixed domain constants.
The multiplier is forced odd, which makes the scramble a bijection modulo two
to the thirty-second and therefore exactly reversible.

Every intermediate product is reduced modulo two to the thirty-second, so
identifiers are portable across hosts of any fixnum width. Six Base58
characters span more than two to the thirty-second values, so every unsigned
32-bit input has one fixed-width encoding.

The format is fixed. The internal alphabet and suffix width define every
identifier already stored.

* Display form

=identifier-display= inserts a hyphen after the seed character, which makes the
two parts distinguishable when a person reads an identifier back. The format
conversion and timestamp functions accept both forms. =identifier-normalize=
converts either to the canonical form. Both conversions signal =identifier-error= on
anything else, so callers holding foreign or legacy values should guard those
calls.

* Matching typed fragments

=identifier-match= selects members of a list by a fragment a person typed. A
fragment equal to one member's identifier, in either form, selects that member
alone. Otherwise every member whose canonical identifier contains the fragment
is returned, compared without regard to case and with the display hyphen
removed from the fragment, so =4P5= and =g-4p5= both find =g-4P5Hsc=. Callers
act on exactly one match and show several back to the person. A =:key=
function reads the identifier from each member, and members whose identifiers
have another shape are compared as their own text.

#+BEGIN_SRC lisp
(idsmall:identifier-match "uWB" '("31uWB8L" "3-1uWC9M"))
;; => ("31uWB8L")
#+END_SRC

* Selecting a prefix

Use =identifier-select= to select one entity by its exact identifier or by a
unique nonempty prefix. Compare arbitrary strings case-sensitively, without
normalization or substring matching. Supply =:key= to read the identifier from
each entity. An exact match takes priority over longer identifiers. No match
returns =nil=. Handle =identifier-ambiguity= when several prefix matches exist;
read the reference and matching identifiers with
=identifier-ambiguity-reference= and =identifier-ambiguity-identifiers=.

Use =identifier-reference= to obtain the shortest prefix that selects an
identifier from a list. Supply =:minimum-length= to set the first length to try;
it defaults to seven and is capped at the full identifier length.

#+BEGIN_SRC lisp
(idsmall:identifier-select "alpha" '("alpha-more" "alpha"))
;; => "alpha"

(idsmall:identifier-reference "alphabet" '("alphabet" "alpine") :minimum-length 1)
;; => "alph"
#+END_SRC

* Allocation

One namespace holds at most =identifier-base= identifiers per second, one per
seed, so allocation checks for collisions. The caller supplies occupancy:

#+BEGIN_SRC lisp
(idsmall:identifier-generate
 :occupied-p (lambda (candidate)
               (probe-file (merge-pathnames (format nil "~A.sexp" candidate)
                                            #p"/var/lib/example/"))))
#+END_SRC

The first seed comes from =*random-index-function*=, which is seeded from the
operating system. A taken candidate causes every remaining seed to be probed
exactly once, so allocation either succeeds or signals
=identifier-space-exhausted= for a full second. Entropy quality only spreads
identifiers across seeds. Bind =*random-index-function*= to make allocation
reproducible under test.

=occupied-p= runs while the allocation lock is held.

* Reservations

A generated identifier is reserved in this process until it is released, so two
threads receive distinct values while the first has yet to persist it.

#+BEGIN_SRC lisp
(let ((identifier (idsmall:identifier-generate :namespace :conversations)))
  (unwind-protect
       (persist identifier)
    (idsmall:identifier-release identifier :namespace :conversations)))
#+END_SRC

Release an identifier once the caller's own storage holds it, or once the work
that requested it is abandoned. A leaked reservation costs one seed for one
second. Reservations are process-local: they coordinate threads. Concurrent
processes sharing storage must make =occupied-p= authoritative.

=:namespace= separates independent identifier spaces in one process; it
defaults to =t=. =identifier-clear-reservations= drops every reservation, which
suits test teardown.

* Timestamp range

=identifier-timestamp= is exact for every universal time below two to the
thirty-second seconds, which covers dates before 2036. Later timestamps encode
and decode modulo that bound.

* Development

#+BEGIN_SRC sh
./script/bootstrap
./script/check
./script/check --fix
#+END_SRC

=./script/check= runs the tests, then checks the source with
[[https://github.com/lambda-symbolics/cheque][cheque]] as =cheque.sexp=
configures it. =--fix= skips the tests and repairs what cheque can repair.
cheque and its tools are development dependencies: =checks/qlfile= lists them,
and the check installs them on first use into =~/.cache/cheque/tools/=.

The tests also run on their own:

#+BEGIN_SRC lisp
(asdf:test-system :idsmall)
#+END_SRC
